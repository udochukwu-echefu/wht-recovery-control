# WHT Recovery Control Workspace

A portfolio MVP for detecting, explaining, and resolving Nigerian withholding-tax receivable exceptions.

The demo includes a synthetic recovery ledger, evidence-chain matching, human-approved follow-up, case lifecycle controls, client-side data intake, and downloadable case packs. It does not provide tax advice or submit information to any tax authority.

## Run locally

```bash
npm install
npm run dev
```

## Product boundaries

- Synthetic data only
- Deterministic matching before AI assistance
- Human approval for consequential actions
- Tax rules and administrative procedures are versioned configuration
